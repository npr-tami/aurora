# research

Tools and notes for mapping the game. Not part of a release; the mod does not use them. All of them only read the game.

| | |
|---|---|
| [grbstatic/](grbstatic/) | Static analysis of the game's executables: build info, patterns, functions, disassembly, xrefs, RTTI |
| [grbresearch/](grbresearch/) | External memory scanner: scans, pointer chains, snapshots, diffs |
| [grbresearch-dll/](grbresearch-dll/) | In-game recorders: write watches and code hit counters |
| [ghidra/](ghidra/) | Headless Ghidra import and decompile by address |
| [scripts/](scripts/) | Small Python helpers |
| [docs/](docs/) | Findings |
